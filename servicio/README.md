# Servicio de triaje financiero AI-SupportAssist

La API FastAPI sirve el modelo de la Fase 2. Descarga el artefacto indicado en la guía principal antes de iniciar la API. La [guía principal](../README.md) explica cómo ejecutar la monitorización y las simulaciones de la Actividad 8.

Para iniciar solo la API con Docker, desde este directorio ejecuta `docker compose up --build`. La documentación de la API se encuentra en `http://localhost:8000/docs`.

Consulta [los metadatos](models/metadata.json) y [la verificación de reconstrucción](evidence/model_reconstruction.json) para revisar la versión y la huella del modelo.
